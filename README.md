# Рассвет · Заготовки

Telegram Mini App для команды бара: заготовки, закрытие смены, наличные, задачи, график, холодильник, техкарты.

**Стек:** React 19 + TypeScript + Vite, TanStack Query (данные с сервера и кеш), Zustand (состояние между вкладками).

## Запуск локально

```bash
npm install
npm run dev
```

Открой http://localhost:5173/?mock — фейковый Телеграм и тестовый сервер в памяти (ничего настоящего не меняется).
Роли: `?mock&role=staff` — сотрудник, `?mock&role=point` — точка Яндекс/Узум, по умолчанию — админ.

## Сборка и публикация

```bash
npm run build      # проверка типов + сборка в dist/
npm run preview    # посмотреть собранное
```

Публикация на GitHub Pages — автоматически при пуше в `main` (`.github/workflows/deploy.yml`).
Один раз в настройках репозитория: **Settings → Pages → Source: GitHub Actions**.

Бот открывает приложение ссылкой `…/bar_prep/?api=<адрес сервера>`, адрес сервера берётся из параметра `api`.

## Структура

```
src/
  main.tsx              запуск: проверка Телеграма, загрузка «me», стартовая вкладка
  app/                  шапка, полоса вкладок (с перетаскиванием), корневой компонент
  api/                  типы ответов сервера и запросы (TanStack Query)
  components/           общие куски: карточки, шторки, фото, поля ввода, вопросы (askQty/askDate)
  features/<вкладка>/   по папке на вкладку: today, count, cash, tasks, events, grafik, fridge, tk, regs, profile, order, admin, help
  lib/                  форматирование чисел/дат/денег, единицы, Telegram, аватарки
  styles/               стили (как были, разбиты по разделам)
  assets/               логотип, аватарки сотрудников, шрифты (WOFF2)
  mock/                 тестовый сервер для локальной разработки (в сборку не попадает)
```

**Новый сотрудник с фото:** положи jpg в `src/assets/avatars/` и добавь строку в `src/lib/avatars.ts`.
**Новая вкладка:** папка в `src/features/`, строка в `src/app/tabs.ts` и в `views` в `src/app/App.tsx`.
